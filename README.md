# E-Commerce Analytics Platform

## Project Overview

This project is an end-to-end E-Commerce Analytics Platform built using Power BI, SQL, and Python. The project analyzes customer behavior, sales performance, product performance, payment trends, and customer satisfaction using the Olist Brazilian E-Commerce dataset.

The objective of this project is to transform raw e-commerce data into meaningful business insights through data cleaning, analysis, visualization, and dashboard development.

# Key Business Insights

- Generated over 20M in total revenue.
- Majority of customers provided positive ratings.
- Credit Card is the most preferred payment method.
- Revenue is highly concentrated in a few states.
- Certain product categories contribute significantly to overall revenue.
- Most orders were successfully delivered.

---

# Business Recommendations

- Increase marketing efforts in high-performing states.
- Focus inventory planning on top-performing product categories.
- Improve customer retention strategies for repeat purchases.
- Promote highly rated products through targeted campaigns.
- Optimize payment experiences based on customer preferences.
